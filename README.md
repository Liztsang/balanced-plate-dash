# Balanced Plate Dash

A simple, senior-friendly nutrition game. Build each meal with:

- 2 vegetable portions
- 1 protein portion (plant-based or animal-based)
- 1 carbohydrate portion

## Run locally

You need Node.js installed.

```bash
npm install
npm run dev
```

## Publish with GitHub Pages

1. Create a public GitHub repository named `balanced-plate-dash`.
2. Upload all files and folders from this project, including `.github`.
3. Open **Settings > Pages**.
4. Under **Build and deployment**, set **Source** to **GitHub Actions**.
5. Open the **Actions** tab and wait for the deployment to finish.
6. Your site will be available at:
   `https://YOUR-USERNAME.github.io/balanced-plate-dash/`

If you rename the repository, update `base` in `vite.config.js` to match the new repository name.

## Build manually

```bash
npm install
npm run build
npm run preview
```
